# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.  
This project was created to practice **DOM manipulation, game logic, and UI design** in web development.

---

## 🚀 Live Demo
You can play the game here:

http://faizanscodeplay.com/

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---

## ✨ Features

- Two-player mode (Player X vs Player O)
- Interactive game board
- Win detection logic
- Draw detection
- Reset game button
- Clean and responsive UI
